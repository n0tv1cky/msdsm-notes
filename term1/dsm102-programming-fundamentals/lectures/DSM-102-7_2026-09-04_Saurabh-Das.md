# DSM-102 · Session 7 (2026-09-04, Saurabh Das): In-Class Python Coding Quiz

> **This was not a lecture.** The session was a live, graded Python coding quiz. The
> questions were pasted into the Zoom chat and never read aloud, so **they are not in the
> recording or the transcript**. Nothing below reconstructs them. For the questions
> themselves, check the chat log, the submission form, or a classmate's copy.
>
> The audio is mostly silence while students worked. The whisper transcript (about 1,200
> words) fills that silence with repeated filler such as "thank you sir" and "the other
> one". Only the few spoken exchanges summarised here are real.

## Quiz format

- **Live, timed, in class.** There were a few minutes to review first. The quiz started
  around 7:15 pm with submissions due by about 8:00 pm, roughly 45 minutes of coding.
- **Five questions in total.** Three were posted to the chat first, and two more followed
  a little later.
- **Write your own code.** The instructor said not to use ChatGPT or any other tool to
  generate answers. Doing so would be "dishonest and not acceptable" and would be
  **penalised**. It did not matter whether the solution fully worked, as long as it was
  your own.

## Submission rules (from students' questions)

- **What to submit:** Python file(s), uploaded through a **form link** the instructor
  shared in the chat during the session.
- **One file or several are both fine.** Each answer could go in its own file, or all
  answers could go in a single file uploaded at the last response of the form.
- **Questions 2 and 3 asked for a Python module.** When a student asked, the instructor
  said to create a **separate module file that you import**: "a module is always a
  separate file". A student who planned to work in a single Colab notebook was told this
  was fine as long as the module was importable.
- **Code alone is sufficient.** The instructor runs the code himself to see the results.
  Including outputs was optional.

## Related material

The quiz drew on what had been taught up to this point, especially Session 6:

- classes;
- writing your own modules;
- NumPy and Matplotlib.

See [Session 6](DSM-102-6_2026-09-01_Saurabh-Das.md) to revise the module-writing pattern
the quiz asked for.
