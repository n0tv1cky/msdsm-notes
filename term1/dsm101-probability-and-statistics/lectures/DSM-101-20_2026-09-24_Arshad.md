## 2. Topics Covered (in order)

### 2.1 Definition: Joint MGF

The joint MGF of the random vector $(X, Y)$ is

$$M_{X,Y}(t_1, t_2) = E\left[e^{t_1 X + t_2 Y}\right],$$

where $t_1 \in (-h_1, h_1)$ and $t_2 \in (-h_2, h_2)$ for some $h_1 > 0$, $h_2 > 0$. That is, $(t_1, t_2)$ lies in a neighbourhood of $(0,0)$.

- The MGF **exists** if this expectation is finite on such a neighbourhood.

### 2.2 Marginal MGFs from the Joint MGF

- Set $t_2 = 0$: $M_{X,Y}(t_1, 0) = E[e^{t_1 X}] = M_X(t_1)$, the marginal MGF of $X$.
- Set $t_1 = 0$: $M_{X,Y}(0, t_2) = E[e^{t_2 Y}] = M_Y(t_2)$, the marginal MGF of $Y$.

### 2.3 Independence via MGFs

**Theorem.** $X$ and $Y$ are independent if and only if

$$M_{X,Y}(t_1, t_2) = M_X(t_1)\, M_Y(t_2)$$

for all $(t_1, t_2)$ in a neighbourhood of $(0,0)$.

- The forward direction ("independent implies factorisation") is immediate.
- The converse also holds, **provided** the factorisation holds on a whole neighbourhood containing $(0,0)$.

### 2.4 Product Moments

The main use of the joint MGF is computing product moments:

$$E[X^r Y^s] = \left.\frac{\partial^{r+s} M_{X,Y}(t_1, t_2)}{\partial t_1^{\,r}\, \partial t_2^{\,s}}\right|_{t_1 = 0,\ t_2 = 0}, \qquad r, s \in \{0, 1, 2, \dots\}.$$

- Differentiating $r$ times in $t_1$ gives the power of $X$.
- Differentiating $s$ times in $t_2$ gives the power of $Y$.

### 2.5 Worked Example 1: Joint MGF of $f(x,y) = e^{-y}$

**Given:**

$$f_{X,Y}(x,y) = \begin{cases} e^{-y}, & 0 < x < y < \infty \\ 0, & \text{otherwise.} \end{cases}$$

**Support.** The region is above the line $y = x$ in the first quadrant. For fixed $x$, $y$ runs from $x$ to $\infty$, and $x$ runs from $0$ to $\infty$.

**Setting up the integral:**

$$M_{X,Y}(t_1,t_2) = \int_0^\infty \int_x^\infty e^{t_1 x + t_2 y}\, e^{-y}\, dy\, dx = \int_0^\infty e^{t_1 x} \int_x^\infty e^{(t_2 - 1) y}\, dy\, dx.$$

**Step 1 (inner integral).** This is finite if and only if $t_2 - 1 < 0$, i.e. $t_2 < 1$. The allowed region contains $0$. Then

$$\int_x^\infty e^{(t_2-1)y}\,dy = \left[\frac{e^{(t_2-1)y}}{t_2 - 1}\right]_x^\infty = 0 - \frac{e^{(t_2-1)x}}{t_2-1} = \frac{e^{(t_2-1)x}}{1 - t_2}.$$

**Step 2 (outer integral).**

$$M_{X,Y}(t_1,t_2) = \frac{1}{1-t_2}\int_0^\infty e^{(t_1 + t_2 - 1)x}\,dx.$$

This is finite if and only if $t_1 + t_2 - 1 < 0$, i.e. $t_1 + t_2 < 1$. Then

$$\int_0^\infty e^{(t_1+t_2-1)x}\,dx = 0 - \frac{1}{t_1 + t_2 - 1} = \frac{1}{1 - t_1 - t_2}.$$

**Result:**

$$\boxed{M_{X,Y}(t_1,t_2) = \frac{1}{(1-t_2)(1-t_1-t_2)}, \qquad t_2 < 1,\ \ t_1 + t_2 < 1.}$$

In the $(t_1, t_2)$ plane, the region is bounded by the lines $t_2 = 1$ and $t_1 + t_2 = 1$. It contains $(0,0)$, so the MGF exists.

**Marginals:**

- $M_X(t_1) = M_{X,Y}(t_1, 0) = \dfrac{1}{1 - t_1}$, for $t_1 < 1$. This is the MGF of an **Exponential(1)** distribution. By uniqueness, $f_X(x) = e^{-x}$ for $x > 0$.
- $M_Y(t_2) = M_{X,Y}(0, t_2) = \dfrac{1}{(1 - t_2)^2}$, for $t_2 < 1$. This is the MGF of a **Gamma** distribution (shape 2, rate 1). Gamma is not otherwise covered in this course.

**Independence check.** $M_{X,Y}(t_1,t_2) \neq M_X(t_1) M_Y(t_2)$, so $X$ and $Y$ are **not independent**. This is already obvious from the support: the range of $Y$ depends on $x$.

**Product moment:**

- $\dfrac{\partial M}{\partial t_1} = (1-t_2)^{-1}(1-t_1-t_2)^{-2}$
- $\dfrac{\partial^2 M}{\partial t_1 \partial t_2} = (1-t_2)^{-2}(1-t_1-t_2)^{-2} + 2(1-t_2)^{-1}(1-t_1-t_2)^{-3}$

At $(0,0)$ this gives $1 + 2 = 3$, so $E[XY] = 3$.

**Other moments:**

- $E[X] = 1$ and $E[X^2] = 2$ (Exponential(1)).
- $E[Y] = 2$.

In the audio the lecturer said "expected value of $X^2$ is two" at the point where the covariance was computed. The value actually used in the covariance is $E[Y] = 2$.

**Covariance:**

$$\text{Cov}(X,Y) = E[XY] - E[X]E[Y] = 3 - (1)(2) = 1 > 0.$$

The covariance is positive, so $X$ and $Y$ are positively related: as $X$ increases, $Y$ tends to increase.

*(Supplementary, not stated in lecture: $E[Y^2] = 6$, so $\text{Var}(Y) = 2$ and $\text{Var}(X) = 1$.)*

### 2.6 Worked Example 2: Identifying Normals from a Joint MGF

**Given:** $M_{X,Y}(t_1,t_2) = e^{t_1^2 + t_2^2}$ for $(t_1, t_2) \in \mathbb{R}^2$. Find $P(X < 0,\ Y < 0)$.

**Recall:** if $X \sim N(\mu, \sigma^2)$, then $M_X(t) = e^{\mu t + \frac{1}{2}\sigma^2 t^2}$ for $t \in \mathbb{R}$.

**Step 1 (factorise).**

$$e^{t_1^2 + t_2^2} = e^{t_1^2} \cdot e^{t_2^2} = M_X(t_1)\, M_Y(t_2).$$

**Step 2 (match to the normal MGF).**

- There is no linear term in $t_1$, so $\mu_X = 0$.
- Matching the quadratic term gives $\frac{1}{2}\sigma_X^2 = 1$, so $\sigma_X^2 = 2$.
- Hence $X \sim N(0, 2)$, and likewise $Y \sim N(0, 2)$.

**Step 3 (independence).** The joint MGF is the product of the marginals, so $X$ and $Y$ are independent.

**Step 4 (compute the probability).**

$$P(X<0, Y<0) = P(X<0)\,P(Y<0) = P\!\left(\frac{X-0}{\sqrt 2} < \frac{0-0}{\sqrt 2}\right) P\!\left(\frac{Y-0}{\sqrt 2} < \frac{0-0}{\sqrt 2}\right).$$

This equals

$$P(Z<0)\,P(Z<0) = \Phi(0)\,\Phi(0) = \frac{1}{2}\cdot\frac{1}{2} = \boxed{\frac{1}{4}}.$$

### 2.7 Worked Example 3: Recovering a Discrete PMF from its MGF

**General form.** If $X$ is discrete with support $\{x_1, \dots, x_n\}$ and probabilities $p_1, \dots, p_n$, then

$$M_X(t) = E[e^{tX}] = \sum_{i=1}^n e^{t x_i} p_i = p_1 e^{x_1 t} + p_2 e^{x_2 t} + \cdots + p_n e^{x_n t}.$$

**Given:**

$$M_X(t) = \frac{2 + e^{-t} + e^{2t} + 2e^{6t}}{6}, \qquad t \in \mathbb{R}.$$

The transcript says "$e$ power 6"; from context this is $e^{6t}$.

**Rewrite in the general form:**

$$M_X(t) = \tfrac{2}{6}e^{0\cdot t} + \tfrac{1}{6}e^{-t} + \tfrac{1}{6}e^{2t} + \tfrac{2}{6}e^{6t}.$$

**Compare term by term** to read off the PMF:

| $x$ | $0$ | $-1$ | $2$ | $6$ |
|---|---|---|---|---|
| $P(X=x)$ | $1/3$ | $1/6$ | $1/6$ | $1/3$ |

**Check:** $\frac13 + \frac16 + \frac16 + \frac13 = 1$.

Any probability, mean or variance can now be computed from this PMF. *(Supplementary: $E[X] = 0 - \frac16 + \frac26 + 2 = \frac{13}{6}$.)*

### 2.8 Worked Example 4: Recognising a Binomial MGF

**Recall:** if $X \sim \text{Bin}(n, p)$, then $M_X(t) = (q + p e^t)^n$ with $q = 1 - p$.

**Given:** $M_X(t) = \left(\tfrac{2}{3} + \tfrac{1}{3}e^t\right)^2$.

**Compare:** this matches with $n = 2$ and $p = \tfrac13$, so $X \sim \text{Bin}\left(2, \tfrac13\right)$. The mean, variance and probabilities follow from the Binomial formulas.

### 2.9 Worked Example 5: Normal and Degenerate Distributions

**Given:** $M_{X,Y}(t_1,t_2) = e^{t_1^2 + t_2}$ for $(t_1, t_2) \in \mathbb{R}^2$.

**Step 1 (factorise).** $e^{t_1^2}\cdot e^{t_2} = M_X(t_1)\,M_Y(t_2)$, so $X$ and $Y$ are **independent**.

**Step 2 (identify $X$).** $X \sim N(0, 2)$, exactly as in Example 2.

**Step 3 (identify $Y$).** $M_Y(t_2) = e^{t_2} = e^{1\cdot t_2}\cdot 1$. This has the discrete form $e^{t y} P(Y=y)$ with $y = 1$ and $P(Y=1) = 1$.

Therefore $Y$ has a **degenerate distribution at $Y = 1$**: all probability mass is at the single point $1$, so $Y$ behaves like a constant.

### 2.10 Worked Example 6: Conditional Expectation for $f(x,y) = 8xy$

**Given:**

$$f_{X,Y}(x,y) = \begin{cases} 8xy, & 0 < x < y < 1 \\ 0, & \text{otherwise.} \end{cases}$$

Find $E[Y \mid X = \tfrac12]$.

**Step 1 (marginal of $X$).**

$$f_X(x) = \int_x^1 8xy\,dy = 8x\left[\frac{y^2}{2}\right]_x^1 = 4x(1 - x^2), \qquad 0 < x < 1,$$

and $0$ otherwise.

**Step 2 (conditional PDF).**

$$f_{Y\mid X}(y \mid x) = \frac{f_{X,Y}(x,y)}{f_X(x)} = \frac{8xy}{4x(1-x^2)} = \frac{2y}{1-x^2}, \qquad x < y < 1.$$

**Step 3 (plug in $x = \tfrac12$).** Here $1 - \tfrac14 = \tfrac34$, so

$$f_{Y\mid X}\left(y \mid \tfrac12\right) = \frac{2y}{3/4} = \frac{8y}{3}, \qquad \tfrac12 < y < 1.$$

**Validity check:**

$$\int_{1/2}^1 \frac{8y}{3}\,dy = \frac{8}{3}\cdot\frac{1}{2}\left(1 - \frac14\right) = \frac43\cdot\frac34 = 1.$$

This is a proper PDF.

**Step 4 (conditional mean).**

$$E\left[Y \mid X = \tfrac12\right] = \int_{1/2}^1 y\cdot\frac{8y}{3}\,dy = \frac83\left[\frac{y^3}{3}\right]_{1/2}^1 = \frac89\left(1 - \frac18\right) = \frac89\cdot\frac78 = \boxed{\frac79}.$$

The conditional variance and other conditional moments can be found the same way.

### 2.11 Worked Example 7: Constants that Make $X$ and $Y$ Independent

**Given** a joint PMF on $\{0,1\}\times\{0,1\}$:

- $p(0,0) = \tfrac16$
- $p(0,1) = a$
- $p(1,0) = \tfrac13$
- $p(1,1) = b$

Find $a$ and $b$ so that $X$ and $Y$ are independent.

**Step 1 (marginals).** Both supports are $S_X = S_Y = \{0, 1\}$.

- $p_X(0) = p(0,0) + p(0,1) = \tfrac16 + a$
- $p_X(1) = p(1,0) + p(1,1) = \tfrac13 + b$
- $p_Y(0) = p(0,0) + p(1,0) = \tfrac16 + \tfrac13 = \tfrac12$
- $p_Y(1) = p(0,1) + p(1,1) = a + b$

**Step 2 (independence condition).** Independence requires $p(x,y) = p_X(x)\,p_Y(y)$ for all $(x,y)$.

**At $(0,0)$:**

$$\tfrac16 = \left(\tfrac16 + a\right)\cdot\tfrac12 \;\Rightarrow\; \tfrac16 + a = \tfrac13 \;\Rightarrow\; a = \tfrac16.$$

**At $(1,0)$:**

$$\tfrac13 = \left(\tfrac13 + b\right)\cdot\tfrac12 \;\Rightarrow\; \tfrac13 + b = \tfrac23 \;\Rightarrow\; b = \tfrac13.$$

**Result:** $a = \tfrac16$ and $b = \tfrac13$.

**Check:** $\tfrac16 + \tfrac16 + \tfrac13 + \tfrac13 = 1$.
