## 3. Topics Covered (in order taught)

### 3.1 Session 3 leftover exercise: random group assignment (student marks data)

**Business problem:** randomly assign each student to one of 6 groups (A–F).

**Step 1: Assign a random integer from 1 to 6.**
```excel
=RANDBETWEEN(1,6)
```
- Enter it in the first student's row and drag down to the last student.
- `RANDBETWEEN` is **volatile**: it recalculates every time you click or edit anything.
- **Fix:** copy the column, then **Paste Special → Values** so the numbers are frozen. Don't keep `RAND`/`RANDBETWEEN` live in a field you need to stay fixed.

**Step 2: Map the number to a group letter.**
- A nested `IF` works but becomes very long with 6 options.
- The **appropriate function is `CHOOSE`**:
```excel
=CHOOSE(B2,"A","B","C","D","E","F")
```
*(Inferred: B2 holds the frozen random number. The column letter was not stated.)*
- How `CHOOSE(index_num, value1, value2, …)` works: if `index_num` = 1 it returns `value1`, if 2 it returns `value2`, and so on.
- **Rule of thumb:** use `CHOOSE` when you have a **fixed, indexed list** of outcomes. It replaces long nested `IF`s.

### 3.2 The weekday-name problem (homework from the previous class)

**Problem:** given today's date, output the day name ("Friday").

```excel
=TODAY()
```
- This returned 18 Sep 2026, a Friday.
- The instructor noted there is no direct function that returns the day name. You can display it via cell formatting, but that doesn't produce the name as a value.

```excel
=WEEKDAY(A1)
```
- This returns 1–7, with the default numbering starting **Sunday = 1**. For Friday it returned **6**.

**Combine with `CHOOSE`:**
```excel
=CHOOSE(WEEKDAY(A1),"Sunday","Monday","Tuesday","Wednesday","Thursday","Friday","Saturday")
```
*(Inferred: A1 holds `=TODAY()`.)*
- ⚠️ The transcript mentions "if I add + three". This was apparently an adjustment while the instructor was fixing the alignment between `WEEKDAY`'s numbering and the order of the `CHOOSE` list. The exact formula with the offset is unclear. With the default `WEEKDAY` (Sunday = 1) and the list starting at "Sunday", no offset is needed.
- Side note, not covered in class: `=TEXT(A1,"dddd")` also returns the day name.

### 3.3 Recap: what Session 3 covered

- **Mixed referencing.** Example: a multiplication table where one factor locks the column and the other locks the row (e.g., `=$A2*B$1`).
- **Circular references.** These occur when a formula refers to a cell that depends on the formula itself. To allow them, go to **File → Options → Formulas → Enable iterative calculation**.
- **Sparklines.** These are in-cell charts.
- **`MAX`, `MIN`, `LARGE`, `SMALL`.** `LARGE` and `SMALL` find the k-th largest or smallest value.
- **`RANK`.** Also covered: array constants use commas to separate elements, e.g., `{1,2,3}`.
- **`CHOOSE`**, for fixed indexed outcomes.
- **Random numbers:** `RAND`, `RANDBETWEEN`, `RANDARRAY`, and **`SEQUENCE`**.
- **`ROW()` / `COLUMN()`.** These return the row or column number and are useful for automation:
```excel
=COLUMN()
=ROW()
```
- **Random ordering without repeats:** combine `RAND` with `RANK`. Example (inferred layout):
```excel
C2: =RAND()
D2: =RANK(C2,$C$2:$C$51)
```

### 3.4 Pivot tables on the travel-spending dataset (925 people)

**Business problem:** decide which customers (roughly the top 20–25% of spenders) should receive advertising material.
- **Fields used:** Gender, Age, Amount Spent on Travel.
- **Guiding principle:** before any analysis or visualization, start with a **question in mind** (the storyboard first). Don't just dump everything into a pivot table.

**Creating the pivot table**
1. Select the data: click the top-left cell, then **Ctrl + Shift + ↓** (and → if needed).
2. **Insert → PivotTable → From Table/Range.** Choose New Worksheet or Existing Worksheet. The instructor used the same sheet.
3. Clicking inside the pivot shows two ribbon tabs: **PivotTable Analyze** and **Design**.

**Name every pivot table (emphasized)**
- Go to **PivotTable Analyze → PivotTable Name**.
- The first question was "Does gender matter?", so the pivot was named something like **PTGender**. The instructor said "PT gender", "PT age", etc.; any clear naming convention works.
- Names become critical later for dashboards and Report Connections.

**Analysis 1: does gender matter?**
- **Drag** fields into the areas. Don't just tick the checkboxes, because Excel then places fields where it chooses.
  - **Rows:** Gender
  - **Values:** Amount Spent on Travel (defaults to Sum)
- Remove the grand total: **Design → Grand Totals → Off for Rows and Columns**.
- Design also offers Report Layout (Compact, Outline, Tabular) and style options.
- **Value Field Settings** (click the field's arrow in Values → Value Field Settings):
  - Changed **Sum → Average**. Male average spend was **slightly higher** than female. The sums were similar.
  - Other options include Count, Max, Min, and Average.
- When **Gender** (a text field) was placed in Values, Excel defaulted to **Count** (it cannot sum text). This gives the number of males and females.
- **Show Values As** tab → **% of Grand Total** gives shares instead of totals.
- **Conclusion:** there is no meaningful gender difference on its own.

**Analysis 2: does age matter?**
- Instead of inserting a new pivot, **copy-paste the existing pivot** (Ctrl+C, Ctrl+V), then rename it (e.g., **PTAge**).
- Remove Gender from Rows and put **Age** in Rows. Set Show Values As back to **No Calculation**.
- **Highlight the top 20%:**
  1. Select **only the numeric value cells**, not the headings or labels. The formatting works on numbers only.
  2. Go to **Home → Conditional Formatting → Top/Bottom Rules → Top 10%**.
  3. Change 10 to **20**, pick a fill colour (e.g., green), and click OK.
  - Highlighted ages: **25, 27, 39, 44, 46, 55**.
- **Value filter (alternative):** use the Row Labels dropdown → **Value Filters → Top 10…**. This keeps only the top N items. Between and other options are also available.
- **Sorting by value, not by label:**
  - Clicking sort on the Age field sorts the **ages**, not the spend.
  - Instead use **More Sort Options → Descending → by Sum of Amount Spent on Travel**.
- **Missing field list:** if the PivotTable Fields pane disappears, go to **PivotTable Analyze → Field List**.

**Analysis 3: age × gender combined**
- Copy the pivot again. Set **Rows = Age**, **Columns = Gender**, **Values = Sum of Amount Spent on Travel**.
- Apply Top 20% conditional formatting to the numeric cells for both the male and female columns.
- The header reads "Sum of Amount Spent on Travel" because that field and aggregation are in Values.

**Pivot chart**
- Click anywhere in the pivot, then **Insert → Line chart**.
- **Pivot chart vs normal chart:** a pivot chart comes with **built-in field filter buttons**, so you can, for example, filter to Male only directly on the chart. Normal charts don't have these.
- The instructor tried other chart types but preferred the line chart.
- **Insight:** **older females and younger males** spend the most. At the individual-age level, high spenders were **age 50 (female)** and **ages 44 and 46 (male)**.

**Grouping and the level of aggregation (key learning)**
- To group: right-click any Age value → **Group** → set the "By" interval.

| Grouping | Top-spending group shown |
|---|---|
| Individual ages | 50 (F); 44, 46 (M) |
| By **10** years | **25–34** |
| By **5** years | **55–59** (male); 44 no longer stands out |
| By **3** years | Different again; top spenders don't match the earlier results |

> **Takeaway:** your insight depends on the level of aggregation. Changing the grouping changes the answer. Grouping is a key pivot feature worth using.

**Empty cells:** go to **PivotTable Options**, where you can specify what to show for empty cells (missing values).

### 3.5 Pivot tables on the sales dataset (in-class questions)

Fields (inferred from usage): Transaction Number, Name (salesperson), Date, Product, Units, Dollars, Location. There are five products, including Lipstick, Foundation, and Eyeliner.

**Q1: How many transactions?** **Answer: 1891.**
- Put a field in Values and set it to **Count**.
- **Count Transaction Number, not Name.** Use a **unique identifier** field, because two people may share a name. Both happened to give the same count here, but Transaction Number is correct in principle.
- If a numeric field defaults to Sum, change it to Count.

**Q2: Total revenue by product**
- Copy the previous pivot. Set **Rows = Product**, **Values = Sum of Dollars**, and remove Transaction Number.
- **Remove the grand totals** (Design → Grand Totals → Off). The instructor stressed this repeatedly because "it doesn't look nice."
- Optionally adjust the Report Layout (Outline/Compact) and style.

**Q3: Jen's lipstick sales as a formula (`GETPIVOTDATA`)**
- Type `=` in a cell, then **click the pivot cell** holding the value. Excel auto-generates the `GETPIVOTDATA` formula. Writing it by hand is complicated.
- Example of the generated form (exact field names and anchor cell inferred):
```excel
=GETPIVOTDATA("Dollars",$A$3,"Name","Jen","Product","Lipstick")
```
- Alternative suggested by a student, which the instructor said is acceptable, though the pivot method is preferred:
```excel
=SUMIFS(Dollars_range,Name_range,"Jen",Product_range,"Lipstick")
```
*(Placeholders. The actual ranges depend on the sheet layout.)*

**Q4: Average unit price per product (calculated field)**
- **Wrong approach:** using Average of Units in Values. This averages the quantity, not the price.
- **Correct approach:** divide total dollars by total units for each product.

$$\text{Price per unit}_{\text{product}} = \frac{\sum \text{Dollars}}{\sum \text{Units}}$$

- Steps:
  1. Click in the pivot (Rows = Product).
  2. Go to **PivotTable Analyze → Fields, Items & Sets → Calculated Field**.
  3. Set **Name:** `Price per unit` and **Formula:** `= Dollars / Units`.
  4. Click **OK**. The new field appears in Values.
- Calculated fields work on the **sums** of the underlying fields. Switching the field to "Average" displays the same result.

**Q5: Sales and quantity sold by salesperson, by location and product**
- Putting everything in one pivot gets very wide and cluttered. **Use one pivot per question**, plus filters.
- Layout: Rows = Name, Values = Sum of Dollars and Sum of Units.

**Slicers**
1. Click the pivot, then **PivotTable Analyze → Insert Slicer**.
2. Tick the fields you want, e.g., **Product** and **Location**.
3. Click items to filter, e.g., Eyeliner or a specific region. Use **Ctrl/Shift-click** (or the multi-select button) to select several.
- A slicer is a visual filter, linked to the pivot it was created from.
- Styles can be changed under the Slicer tab.

**Timeline**
1. Go to **PivotTable Analyze → Insert Timeline**. Only **date fields** appear, because timelines only work on dates.
2. Switch the period level among **Years / Quarters / Months / Days**. The instructor selected **April** at the month level.

### 3.6 Dashboard build (started; to be completed next session)

**Objective:** a dashboard where clicking a salesperson in a slicer updates "Sales of Selected" while "Total Sales" stays fixed. The final dashboard will have about five connected pivot tables, and a reference image was shared so students can check their work.

**Workbook layout**
- Create a new workbook (saved as "dashboard class") and copy in the **sales data**.
  - The instructor first pasted the travel data by mistake. That gave a total of 8409, which is **not** the correct figure.
- **Pivot sheet:** all supporting pivot tables kept in one place.
- **Dashboard sheet:** labels, KPI cells, and slicers. Turn off gridlines via **View → uncheck Gridlines**.

**KPI 1: Total (overall) sales**
1. **Insert → PivotTable → From Table/Range → Existing Worksheet** (on the pivot sheet).
2. **Name it PTTotal.** The instructor stressed this as "very critical".
3. Values = **Sum of Dollars**, with nothing in Rows. This gives the company total.
4. On the dashboard, next to the "Total Sales" label, type `=` and click the PTTotal value cell (inferred):
```excel
=GETPIVOTDATA("Dollars",Pivots!$A$3)
```
- Correct total ≈ **2,39,000** (₹2.39 lakh, as stated verbally).

**Slicer**
- Select PTTotal → **Insert Slicer → Name**.
- **Cut** the slicer and **paste** it onto the dashboard sheet.

**KPI 2: Sales of selected salesperson**
1. Copy PTTotal, paste it, and rename the copy **PTSelected**.
2. Put **Name in Rows** and **keep the grand total** for this one.
3. On the dashboard, "Sales of Selected" = `=` and click PTSelected's **Grand Total** cell (inferred):
```excel
=GETPIVOTDATA("Dollars",Pivots!$E$3)
```

**Problem:** clicking a name in the slicer changes **both** KPIs. The copy inherits the slicer link, so both pivots respond.

**Fix: Report Connections**
1. Right-click the slicer → **Report Connections**.
2. The dialog lists every pivot table the slicer can control (this is where naming pays off).
3. **Uncheck PTTotal** and keep **PTSelected** checked.
4. Click **OK**.

- **Result:** Total Sales stays at about 2,39,000, while Sales of Selected changes with each slicer click.
- **Key dashboard concept:** some components respond to filters and some stay fixed. Report Connections controls which is which.
