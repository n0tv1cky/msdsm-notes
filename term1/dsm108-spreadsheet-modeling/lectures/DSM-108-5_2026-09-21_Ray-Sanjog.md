## 2. Topics Covered (in order taught)

### 2.1 Ground Rules for Multi-Pivot Dashboards

**No overlapping pivot tables.**
- Each pivot table must have room to expand to its **full size**, meaning with all filters cleared.
- When a slicer filters a pivot down to one row, it may look small. If you place another pivot just below it, the first pivot will collide with the second when the filter is cleared, and Excel throws an error.
- **Before placing each new pivot:** clear all slicer selections, look at the full extent of the existing pivots, then place the new one in clear space.
- To judge pivot sizes, the instructor sometimes removed the slicer temporarily.
- If you get an error when copying or creating pivots, overlap is the most likely cause. Clear all filters and check.

**Name every pivot table.**
- Use PivotTable Analyze → PivotTable Name.
- Names make Report Connections readable. Unnamed pivots show up as defaults such as "PivotTable86", which are impossible to track.
- The instructor's names (spoken as "PT all", "PT select", and so on) are written here as:

| Name | Purpose |
|---|---|
| **PTAll** | Total sales |
| **PTSelect** | Selected sales |
| **PTPie** | Donut chart ("PTI" in the audio) |
| **PTHeat** | Heat map |
| **PTBar** | Price-per-unit bar chart |
| **PTSpark** | Sparklines |

**Build each new pivot by copying the first one.**
- Copy PTAll, paste it in a clear area, then rearrange its fields.
- The slicer should also be created from the first pivot. Every other pivot is a copy of it, which avoids connection issues.

**Keep the dashboard clean.**
- Remove gridlines: View → uncheck Gridlines.
- Hide chart field buttons.
- Remove chart fill and outline.
- Do not scatter elements randomly.

### 2.2 KPI 1: Total Sales (pivot PTAll)

**Steps:**
1. Select the data, then Insert → PivotTable → From Table/Range → Existing Worksheet (choose a clear area).
2. Fields: put **Dollars** in Values, giving Sum of Dollars. Nothing goes in Rows or Columns.
3. Name the pivot **PTAll**.
4. On the dashboard, label a cell "Total Sales" (the instructor shaded it yellow).
5. In the next cell, type `=` and **click the pivot's value cell**. Excel automatically writes a `GETPIVOTDATA` formula.

```excel
=GETPIVOTDATA("Dollars",'Pivots'!$A$3)
```

*Inferred:* the sheet name and anchor cell depend on where your pivot sits. Let Excel generate this by clicking. Do not type it by hand.

**Common mistake:** pasting the value instead of linking it. One student pasted the number. The fix was to type `=`, go to the pivot sheet, click the "Sum of Dollars" value cell, and press Enter. That activates `GETPIVOTDATA`.

**Formatting:** adding a currency symbol is optional.

**Requirement:** this value **must never change** when the slicer or timeline is used.

### 2.4 KPI 2: Selected Sales (pivot PTSelect) and Report Connections

1. Copy PTAll and paste it into a non-overlapping area. It should still be Sum of Dollars only.
2. Name it **PTSelect**.
3. On the dashboard, label a cell "Sales Selected" and link it with `=` + click:

```excel
=GETPIVOTDATA("Dollars",'Pivots'!$A$10)
```

*Inferred cell; generate it by clicking.*

At first, both KPI cells show the same number, because both pivots respond to the slicer. To fix this:

**Report Connections workflow:**
1. Right-click the slicer → **Report Connections…**
2. **Uncheck PTAll** and **check PTSelect**.
3. Rule: any pivot that is checked changes when you click the slicer.

**Result:** Total Sales stays fixed, and Selected Sales responds to the slicer.

### 2.7 Heat Map: Product × Month (pivot PTHeat)

Target layout: products down the side, months across the top, numbers only (color comes later).

1. Copy a pivot into clear space and name it **PTHeat**.
2. Fields:
   - **Rows:** Product
   - **Columns:** Date. Excel auto-groups dates; in older versions it splits them into Years, Quarters and Months. Remove everything except **Months**.
   - **Values:** Sum of Dollars
3. Design: remove grand totals and reduce the font size of the values.
4. **New feature: Move PivotTable.**
   - Select the pivot, then PivotTable Analyze → **Move PivotTable** → set the location to the heat-map area on the dashboard.
   - The pivot itself lives on the dashboard, rather than a linked copy.
5. Home → **Conditional Formatting → Color Scales** → the green–yellow–red scale ("green red").
6. Hide the numbers so only the colors show:
   - Right-click → Format Cells → Number → Custom
   - Type `;;;` (three semicolons) as the format code.

```
;;;
```

7. Narrow the columns. The instructor set the column width to **5**, because the default made the cells collapse too much.
8. **Report Connections:** right-click the slicer → **check PTHeat**. The instructor flagged forgetting this as a common mistake.

### 2.8 Bar Chart: Average Price per Unit by Product (pivot PTBar)

**Calculated field:**
1. Copy a pivot into clear space and name it **PTBar**.
2. PivotTable Analyze → Fields, Items & Sets → **Calculated Field**.
3. Name: **Price per Unit**.
4. Formula:

```excel
= Dollars / Units
```

In math form:

$$\text{Price per Unit} = \frac{\text{Dollars}}{\text{Units}}$$

> **Note (not from lecture):** a pivot calculated field is evaluated on the summed fields. It actually computes $\frac{\sum \text{Dollars}}{\sum \text{Units}}$ per product, which is a weighted average price. Changing the summary to "Average" does not alter that behavior.

**Pivot layout and formatting:**
- **Rows:** Product
- **Values:** Price per Unit. The instructor said "make it average".
- Design: remove subtotals and grand total.
- Number format: **4 decimal places**.
  - The prices are all close together (around 3.05).
  - At 2 decimals the bars and labels look identical, even though the underlying values differ.
  - A student's emailed dashboard had equal-looking bars for this reason. The instructor explicitly asked the class to switch to 4 decimals.

**Chart:**
1. Insert a bar/column chart.
2. Add **Data Labels**.
3. Optionally recolor it (green was used).
4. Format the chart area with **No Fill** and **No Outline**, for a cleaner look.
5. Cut the chart and paste it onto the dashboard.
6. **Report Connections:** check **PTBar**.

**Placement tip:** if widening the columns under the chart also stretches the chart, move the chart elsewhere. Charts resize with cells.

### 2.9 Sparklines: Quarterly Trend per Product (pivot PTSpark)

1. Copy a pivot into clear space.
2. Fields:
   - **Rows:** Product
   - **Values:** Sum of Dollars
   - **Columns:** Date grouped by **Years and Quarters**. Remove Months.
3. **Expand the quarters** with the + button. They are collapsed by default, and without them the sparkline is too short to show a trend.

5. Label the dashboard column header "Year / Quarter" (the year-wise trend).

   - Going the other way (selecting the data first) often fails because the range won't pick up.
7. Rename the pivot. It had a default name like "PivotTable86". Name it **PTSpark**.
8. **Report Connections:** check **PTSpark**.

### 2.12 Formula-Based Analysis ("Functions" Sheet)

**Setup:**
1. Copy the full dataset to a new sheet named **Functions**.
2. Copy the **Name** column to a free area. Per the audio, the unique list starts around **J3**.
3. Data → **Remove Duplicates**, leaving a unique salesperson list.
4. **Name the ranges** (select a column, then type in the Name Box):

| Range name | Contents |
|---|---|
| `Dollars` | Dollars column |
| `Units` | Units column |
| `Name` | Salesperson name column |

Named ranges save you from reselecting ranges every time. Exact column letters and row extents are inferred.

**Functions you must know:**

| Function | Use |
|---|---|
| `SUMIF` | Sum with one condition |
| `SUMIFS` | Sum with multiple conditions |
| `COUNTIF` | Count with one condition |
| `COUNTIFS` | Count with multiple conditions |

Use the **fx** button (Insert Function) to get the argument dialog.

**Q1: Total dollar sales for each salesperson (one condition)**

```excel
=SUMIF(Name,J3,Dollars)
```

- Arguments:
  - **Range:** `Name`, where the criterion is tested
  - **Criteria:** `J3`, the salesperson in the unique list (for example "Betsy")
  - **Sum_range:** `Dollars`
- Drag down. `J3` is a relative reference, so it becomes J4, J5, … automatically.
- Because the named ranges are fixed, there is no need for `$`.

**Q2: Betsy's total sales where Units > 1 (two conditions, so SUMIFS)**

`SUMIF` won't work here, because there are two conditions: Name = Betsy and Units > 1.

```excel
=SUMIFS(Dollars,Name,"Betsy",Units,">1")
```

You can also reference the cell holding "Betsy":

```excel
=SUMIFS(Dollars,Name,J3,Units,">1")
```

- `SUMIFS` takes `Sum_range` **first**, then pairs of criteria range and criteria.
- The order of the criteria pairs doesn't matter. Putting Units first and Name second gives the same answer.

**Discussion of a student's error:**
- A student used column-letter ranges (something like `F:F`, which the audio rendered as "FF") instead of named ranges.
- When the instructor reproduced this with mismatched ranges (for example `F1:F...` against a different-length range), he got `#VALUE!`. Evaluate Formula showed the range sizes/types didn't match.
- **Takeaway:** in `SUMIFS`/`COUNTIFS`, all ranges must be the same size. Use named ranges or consistent ranges, and be careful when typing raw column references.

**Q3: Number of transactions where units sold is negative**

```excel
=COUNTIF(Units,"<0")
```

- **Range:** `Units`
- **Criteria:** `"<0"`

**Q5 (exam-style "trick" question): Number of transactions with units above the average**

Step 1: compute the average in its own cell (cell inferred, for example L10):

```excel
=AVERAGE(Units)
```

Step 2: count transactions above it. **Do not hard-code the average.**

```excel
=COUNTIF(Units,">"&L10)
```

- **Answer in class: 917.**
- **Why `">"&L10`:**
  - Writing `">L10"` (the cell reference inside the quotes) returns **0**. Excel treats it as literal text and cannot read it as a cell.
  - Put the operator in double quotes and join it to the cell with `&`.
- **`&` operator:** concatenates text. For example, `"xx" & "yy"` gives `"xxyy"`. `CONCAT` (or other text functions) is an alternative.

**Aside on versions:** the instructor prefers formulas because almost all of them exist in every Excel version. Some newer dynamic-array functions (`FILTER`, `SORTBY`) are not in older Excel; they will be covered next session.

**Text-function exercise** (to be solved in class tomorrow, but try it first):
- Given a full name in one cell (for example "First Middle Last"), extract the **First**, **Middle** and **Last** names into separate cells automatically.
- The logic the instructor gave:
  - Everything before the **first space** is the first name.
  - The text between the **first space** and the **second (last) space** is the middle name.
  - Everything after the second space is the last name.

**Possible approach (not given in lecture; check against tomorrow's solution).** Assume the name is in A2:

```excel
First:  =LEFT(A2,FIND(" ",A2)-1)
Middle: =MID(A2,FIND(" ",A2)+1,FIND(" ",A2,FIND(" ",A2)+1)-FIND(" ",A2)-1)
Last:   =RIGHT(A2,LEN(A2)-FIND(" ",A2,FIND(" ",A2)+1))
```
