### 2.1 Homework recap: Hierarchy (parent–child) charts → Treemap

**Business problem:** The dataset lists companies and their sales. Some companies belong to a parent company. The task was to make one chart showing the parent company with its sales as well as each individual company with its sales. (The ASR rendered this as "parent company with ISL … individual company with cells.")

**General principles:**
- In visualization there are many technically correct charts. Pick the one that is **easiest to read and communicate**.
- For parent/child (label hierarchy) data, the three popular chart types to remember are:
  1. **Treemap**
  2. **Sunburst**
  3. **Decomposition tree**

**How Excel reads hierarchy data (key logic):**

| Column 1 | Column 2 | Column 3 |
|---|---|---|
| **Parent** | **Child** | **Value** |

If the data is not in this order, Insert → Treemap will not plot the hierarchy correctly.

**Workflow:**
1. Split raw data if needed (Data → **Text to Columns**; see 2.2 for the delimiter).
2. **Cut and rearrange the columns** into Parent | Child | Value order.
3. Select the whole range and choose **Insert → Hierarchy chart → Treemap**.
4. Improve it:
   - Right-click → **Format Data Series** → Series Options → Label Options → **Banner**. This puts the parent name as a heading banner at the top of each group.
   - Optionally use Chart Design to change colors and style.
5. Add values: right-click → **Format Data Labels** (the bar/column icon in the pane) → tick **Value**.
6. Resize the chart; the treemap re-tiles automatically.

### 2.2 Better chart for this scenario: **Pie of Pie** (built-in)

**When to use:** Only **one** company has a parent/sub-breakdown, i.e., one category has subcategories. If **multiple** companies have children, Pie of Pie does not work, so use a treemap or sunburst instead. This category-plus-subcategory situation is common.

**Step 1: Split the data with Text to Columns**
- Select the column → **Data → Text to Columns** → Delimited → Other: `|`.
- ⚠ **Inferred:** The instructor said "put capital I as other." In context this is almost certainly the **pipe character `|`** used as the delimiter in the raw data. It is visually similar to a capital I. Check the actual file.

**Step 2: Arrange the data so Excel knows where to "break"**
- Pie of Pie splits the series by **Position**, **Value**, **Percentage**, or **Custom**. The instructor used **Position**.
- With Position, Excel counts **from the bottom of the list**. "Values in second plot = 3" means the **last 3 rows** go into the second (small) pie.
- So **cut the child rows of the parent company and paste them at the bottom** of the data. In the example there were 3 child rows.

**Step 3: Build and format**
1. Select the data → **Insert → Pie → Pie of Pie**.
2. Right-click → **Format Data Series** → **Split Series By: Position** → **Values in second plot: 3**.
   - Setting it to 4 would take the last 4 rows.
3. Add data labels: right-click → **Format Data Labels** → tick **Category Name** (plus Value).
4. **Percentages instead of values:** In Format Data Labels, tick **Percentage** and untick **Value**. Excel does this automatically; no manual calculation is needed. The underlying data was shipments in millions.
5. Excel labels the combined slice **"Other."** Click that label and rename it to the parent company's name.
   - ⚠ The ASR says "BKK," which is probably a misheard company name.
6. **Make it clean.** Tidy colors, labels, and title.

**Instructor's warning:** A student's chart looked similar, but its numbers didn't match. That made it a *different* chart. Always verify that your numbers match the target chart.

### 2.4 Line chart: 2016 actual vs. 2017 forecast (dotted)

**Problem:** Monthly sales data for 2016 (actual) and 2017 (forecast). Show the trend so that the **2017 forecast portion is clearly distinguishable**: dotted line, 2016 solid.

**KEY RULE (repeated by the instructor, "we'll use it multiple times"):**
> **In Excel, each column is a separate series, and each series gets its own color/format.**
> **Number of columns = number of colors you want in the chart.**
> If you want five colors, arrange the data in five columns.

**Workflow:**
1. **Text to Columns** with delimiter `|` (⚠ same "capital I" issue as above).
2. **Cut the 2017 values** into a new adjacent column headed **"Forecasted Sales."** The 2016 values stay in the "Sales" column.
3. Select everything → **Insert → Line chart**.
4. **Fix the gap.** There is a break between Dec 2016 and Jan 2017 because neither column has a value at the junction. **Copy the junction value into both columns** so the two lines connect.
   - The junction value was **34,000** in the example.
   - ⚠ **Inferred:** The transcript says "2017 first month January… that 34,000 copied here." The bridging value at the boundary point appears in both columns. Which exact row it sits on depends on the file.
5. **Clean the chart:**
   - Remove the repeated year labels ("2016" and "2017" repeated on every month) so each year appears once on the axis.
   - Select the forecast series → **Format Data Series → Line → Dash type: dotted/dashed**.
   - Optionally add markers: Format Data Series → **Marker → Marker Options → Built-in**.
   - Optionally tick **Smoothed line**. The instructor uses this often for looks, but noted it's "not a right idea" analytically.

Layout:

| Month | Sales (2016) | Forecasted Sales (2017) |
|---|---|---|
| Jan-16 … Dec-16 | values | (blank) |
| junction month | 34,000 | 34,000 |
| … 2017 months | (blank) | forecast values |

### 2.5 In-cell charting (for dashboards), using the Session 2 data file

**Concept:** "In-cell charting" means the visual indicator lives **inside the cell**, not in a separate chart object. It is used heavily in **dashboards**, which will be built later in the course.

**Sheet layout (⚠ inferred from "applied to D3 to D13"):**

| Col | Content |
|---|---|
| B | Month (Jan–Dec) |
| C | Sales (Jan in row 2, Dec in row 13) |
| D | Status (formula, D3:D13; row 2 has no prior month) |

#### (a) Status indicator with an IF formula + icon set

Logic: compare each month to the previous month.
- Greater than the previous month gives **+1** (green).
- Less than the previous month gives **−1** (red).
- Equal gives **0** (yellow).

```excel
=IF(C3>C2,1,IF(C3<C2,-1,0))
```

Enter this in D3 and drag down to D13. This is a nested IF.

Notes from class:
- Don't forget the **equal (0) case**. One student's formula lacked it.
- You don't need to output words like "red/green"; numbers are enough.
- **Show formulas:** **Formulas → Show Formulas** toggles between showing formulas and results. The shortcut is `` Ctrl+` ``.
- **Exam point:** Any correct method gets marks unless the question specifies a technique. Some methods are more efficient.

**Turning numbers into traffic lights:**
1. Select **D3:D13** → **Home → Conditional Formatting → Icon Sets** → choose the 3-icon set (green/yellow/red circles or traffic lights).
2. Hide the numbers: **Conditional Formatting → Manage Rules**.
   - If the rule isn't listed, change "Show formatting rules for" from *Current Selection* to **This Worksheet**. It then shows the rule applied to `=$D$3:$D$13`.
3. **Edit Rule** → tick **Show Icon Only** → OK.
4. The Edit Rule dialog also shows the thresholds that decide green/yellow/red.
   - The default 3-icon rule uses percent of range: green when $\ge 67\%$, yellow when $\ge 33\%$.
   - For values in $\{-1, 0, 1\}$ this maps +1 to green, 0 to yellow, and −1 to red.
   - You can switch the type to *Number* with thresholds 1 and 0 for clarity. (This is an addition, not shown in class.)
5. The icons update automatically if sales values change.

#### (b) Status with text arrows

1. In three helper cells, insert arrow characters via **Insert → Symbol** (normal text arrows): up arrow, down arrow, and an "equal" (sideways) arrow.
   - ⚠ **Inferred:** helper cells shown here as G1 (up), H1 (down), I1 (equal).
2. Copy the same IF formula and replace 1/−1/0 with **absolute** references to the arrow cells. Press **F4** to add the `$`s.

```excel
=IF(C3>C2,$G$1,IF(C3<C2,$H$1,$I$1))
```

Drag down to row 13. You can enlarge the font so the arrows read better.
- Tip: if you can't find F4, check whether your laptop requires `Fn+F4`.

#### (c) In-cell bar chart with `REPT`

`REPT(text, number_times)` repeats a text string a given number of times.

```excel
=REPT("|",C2/10000)
```

Drag down for all 12 months.
- ⚠ **Inferred:** The instructor said "I'll put a capital I." It is likely the pipe `|`, though a literal `"I"` works too. Any symbol can be repeated.
- Scaling: dividing by 10,000 keeps bar lengths reasonable. `REPT` drops the decimal part, so the number of characters is
$$n = \left\lfloor \frac{\text{Sales}}{10000} \right\rfloor$$
  For example, sales of 34,000 give $\lfloor 3.4 \rfloor = 3$ bars.
- Use: visually spot that **February is the best month** (the longest bar).
- Highlighting the max in red is **not** automatic. You'd need to do it manually or with conditional formatting.
- The instructor mentioned there is **one built-in in-cell charting tool** to be covered later. This is likely **Sparklines** (⚠ inferred).

### 2.6 Hiding formulas (so recipients can't see them)

Use case: you email a model and don't want others to see your formulas. Many downloadable retirement-planning and portfolio templates are built this way.

**Two steps; both are required:**
1. Select the formula cells → right-click → **Format Cells → Protection** tab → tick **Hidden** → OK.
   - At this point formulas are *still visible*. Hidden only takes effect once the sheet is protected.
2. **Review → Protect Sheet** → enter a password → confirm.
   - Now the formula bar shows nothing for those cells.
   - Right-click and format options are also disabled while the sheet is protected.

To undo: **Review → Unprotect Sheet** (enter the password).

### 2.7 Password-protecting the whole file

**File → Save As → More options… → Tools (next to Save) → General Options** → set a password to open and/or modify.

The recipient needs the password to open the file. This works the same way as in Microsoft Word.

### 2.8 Handling missing data in a line chart

**Scenario:** The **October** sales value is missing.

Options discussed:
- **Impute with mean or median.** Suggested by a student; a valid approach.
- **Do not put 0.** It creates a false crash in the line.
- **Connect the neighboring points:**
  - Enter `=NA()` in the missing cell:
    ```excel
    =NA()
    ```
  - Or leave the cell blank.
  - Then right-click the chart → **Select Data → Hidden and Empty Cells** → "Show empty cells as": *Gaps / Zero / **Connect data points with line***.
  - Also tick **"Show #N/A as an empty cell"** so `=NA()` is treated like a blank and gets connected.

**Interpretation caution (important concept):**
- Connecting the points implies the line goes straight from September to November. We **don't know** the true slope.
- The real value could be higher or lower, so the straight connector **misleads** the viewer into thinking October has a known value.
- A student suggested markers can help show which points actually exist.

### 2.9 Axis manipulation can mislead

- **Format Axis → Bounds (Minimum/Maximum) and Major units.**
- Changing the minimum or maximum can make a small change look dramatic, or a big one look flat. The instructor demonstrated changing the bounds, mentioning 50,000 as a value that's "too much."
- Always check axis values before interpreting a chart, and don't manipulate them to distort.

### 2.10 Target vs. Actual by state → Bullet chart (combo chart)

**Problem:** For each Indian state you have a **Target** and an **Actual**. Find the **worst-performing state**.

**What makes a good chart:**
- You should read the answer *instantly* without studying the chart. If you have to study it, it's a bad chart, even if technically correct.
- One student, from a basic chart, answered "Rajasthan." The properly built chart shows otherwise.

**Answer from the finished chart:**
- Only **Gujarat** and **West Bengal** fall below target.
- **West Bengal is the worst.**
- All other states exceeded target.

**Chart type:** a variation of the **bullet chart**, built as a **combo chart**. The actual is a thin bar inside a wider target bar.

**Workflow:**
1. Select State, Target, and Actual → **Insert → Clustered Column**.
2. Format Data Series:
   - Put **Target** on the primary axis.
   - Put **Actual** on the **secondary axis**. (The instructor first said the reverse, then settled on Actual = secondary.)
3. Adjust **Gap Width**:
   - Target: **decrease** gap width, making a wide bar.
   - Actual: **increase** gap width, making a thin bar that sits inside the target bar.
4. **Critical fix: equalize the two axes.**
   - By default the primary axis max was **5** and the secondary max was **4.5**. This made the chart *wrong*: Actual bars appeared below target when they weren't.
   - Right-click the 4.5 axis → **Format Axis → Bounds → Maximum = 5**.
   - Once both axes match, **delete the secondary axis** since it's redundant.
5. Manually recolor the bars for Gujarat and West Bengal to flag the problem states.

> **Rule:** Whenever a chart has **two axes**, they **must be on the same scale** (same min/max). Otherwise the chart shows wrong information.
