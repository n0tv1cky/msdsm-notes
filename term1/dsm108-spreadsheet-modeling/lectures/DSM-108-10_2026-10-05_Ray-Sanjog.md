The quiz marks shown add up to 22 + 22 + 6 = 50.

#### Q1 (22 marks): Pivot table, % change, conditional-color chart

1. **Build a pivot table** to get the 2022 and 2023 values side by side, with years as columns.
2. **Compute the percentage change** (about 5 marks):
   $$\%\,\text{change} = \frac{V_{2023} - V_{2022}}{V_{2022}}$$
   ```excel
   =(C5-B5)/B5
   ```
   *(Cell refs inferred: B = 2022, C = 2023.)*
3. **Build a helper table with IF** (the highest-weighted part, about 8–10 marks). It splits values into "greater than" and "less than" columns so each series gets its own colour. The course rule is: **multiple columns = multiple colours**.
   ```excel
   =IF(D5>0, D5, NA())      ' positive-change series
   =IF(D5<0, D5, NA())      ' negative-change series
   ```
   *(Exact layout inferred.)* The instructor said using `0` instead of `NA()` also works.
4. **Create the chart** with titles and axis names (about 1 mark for names) and correct colours (5 marks). If the helper table is built correctly, the colours come automatically.

> Key point: "The main thing was [the] table." Without the IF helper table you could score near zero on the chart portion.

#### Q2 (22 marks): RANK + VLOOKUP cut-off table + conditional formatting

1. **Rank the values.** The rank must be computed with a formula, not hardcoded.
   ```excel
   =RANK.EQ(B2,$B$2:$B$101,0)
   ```
   *(Range inferred.)*
2. **Build a VLOOKUP lookup table** (the key part, about 10–12 marks).
   - The cut-off ranks for categories such as "Top" and "Between" must be **driven by an input percentage**, e.g. top 1%.
   - Changing the percentage must change the cut-off ranks and the resulting labels.
   - **Only VLOOKUP was allowed.** Other functions scored zero.

   A plausible reconstruction (cell addresses inferred):
   ```excel
   ' Input:   H1 = top % (e.g., 1%)
   ' Lookup table (sorted ascending by rank in the first column):
   ' J2: 1                                  K2: "Top"
   ' J3: =ROUNDUP($H$1*COUNT($B$2:$B$101),0)+1   K3: "Between"
   ' ... further rows as required by the question
   =VLOOKUP(C2,$J$2:$K$4,2,TRUE)      ' approximate match
   ```
3. **Apply conditional formatting data bars** (2 marks).

#### Q3 (6 marks): Filter

- Apply a filter on the Customer field: **Value Filters → Top 10 → change to Top 1**.
- This question was all-or-nothing: 6 marks or 0.

### 2.2 Macro Recording (Developer Tab)

**Concept:** "Record Macro" works like a phone camera. Every action you take in the workbook between *Record* and *Stop* is recorded as VBA code that can be replayed.

The class used the ratio-analysis file from the previous session.

#### Step 0: Preserve the formula

- Copy the existing IF "status" formula from the sheet into Notepad.
- You will re-enter it while recording.

#### Macro 1: `Clean`

1. Go to **Developer → Record Macro**, name it `Clean`, and click **OK**.
2. Select the sheet contents and delete everything.
3. Click **Developer → Stop Recording**.

#### Macro 2: `Status`

1. Go to **Developer → Record Macro**, name it `Status`, and click **OK**.
2. Paste or type the IF formula into its cell(s).
3. Click **Stop Recording**.

You can view both macros under **Developer → Macros**.

#### Assigning macros to buttons

1. Go to **Developer → Insert → Form Controls → Button**.
2. Draw the button. The *Assign Macro* dialog opens; choose `Clean`.
3. Rename the button caption to "Clean".
4. Repeat for a "Status" button assigned to `Status`.

#### Exercise: Navigation buttons between sheets

This is common in multi-sheet models, e.g. income-tax Excel utilities with buttons that jump between sheets.

1. Record a macro `RTA` (Ratio Trend Analysis):
   - start recording while on the Ratio Analysis sheet
   - click the Ratio Trend Analysis sheet tab
   - stop recording
2. Record a macro `RA`:
   - start on the Ratio Trend Analysis sheet
   - click the Ratio Analysis tab
   - stop recording
3. Place a button on Ratio Analysis assigned to `RTA` (caption "Ratio Trend").
4. Place a button on Ratio Trend Analysis assigned to `RA`.

#### Editing the recorded VBA

- **Goal:** change the status label from "Worse" to "Bad" without rewriting the formula on the sheet.
- **Steps:**
  1. Right-click the Status button and choose **Assign Macro**, or go to **Developer → Macros**.
  2. Select `Status` and click **Edit** ("View code").
  3. In the VBA editor, change `"Worse"` to `"Bad"`.
  4. Save. The change is reflected when the macro runs.

The structure is `Sub … End Sub` blocks. The code below is a typical reconstruction; exact cell addresses, sheet names, and the IF condition were not stated and are **inferred**.

```vba
Sub Clean()
    Cells.Select
    Selection.ClearContents
End Sub

Sub Status()
    Range("D5").Select
    ActiveCell.FormulaR1C1 = "=IF(RC[-1]>RC[-2],""Better"",""Bad"")"   ' was ""Worse""
End Sub

Sub RTA()
    Sheets("Ratio Trend Analysis").Select
End Sub

Sub RA()
    Sheets("Ratio Analysis").Select
End Sub
```

#### Saving

- A normal `.xlsx` file will **not** keep macros.
- Use **File → Save As → Excel Macro-Enabled Workbook (`.xlsm`)**, especially before emailing the file to someone.

> **Recap of the three macro skills:** (1) record a macro, (2) view and edit the code, (3) save as `.xlsm`.

### 2.4 Descriptive Statistics: Four Stocks

**Business problem:** Daily prices of four stocks (including Microsoft, GM, and Intel). Find the mean, median, mode, and so on.

**Sample vs population (student question):**
- Treat the data as a **sample**, because it covers only a time window.
- The population would be every price since the stock was listed.
- So use `STDEV.S`, not `STDEV.P`:
  $$s = \sqrt{\frac{\sum (x_i - \bar{x})^2}{n-1}}$$

**Formula approach (column B shown):**
```excel
=AVERAGE(B2:B253)
=MEDIAN(B2:B253)
=MODE.SNGL(B2:B253)
=STDEV.S(B2:B253)
```
*(Range inferred.)*

**ToolPak workflow:**
1. Go to **Data → Data Analysis → Descriptive Statistics → OK**.
2. **Input Range:** all four columns, *including header names*.
3. **Grouped By:** Columns.
4. Check **Labels in first row**, since headers were selected.
5. **Output Range:** a cell on the same sheet. (New Worksheet Ply is also possible.)
6. Check **Summary statistics**. This is essential; without it you get nothing useful.
7. Confidence Level for Mean is optional.
8. Click **OK**.

**Output:** mean, standard error, median, mode, standard deviation, sample variance, kurtosis, skewness, range, min, max, sum, and count for each stock, produced in about one second.

### 2.5 Correlation Matrix and Highlighting the Highest Positive Correlation

**Question:** Which two stocks have the highest positive correlation? Highlight that cell **using a formula**, so the highlight still works if the data changes.

- Several students highlighted manually or got two highlights. Both are wrong: there is only one answer.
- **Answer: Intel and Microsoft.**

**ToolPak workflow:**
1. Go to **Data → Data Analysis → Correlation → OK**.
2. **Input Range:** select all columns with headers. Ctrl+Shift+↓ helps select to the bottom.
3. Check **Labels in first row**.
4. Set an **Output Range** and click **OK**.

The output is a lower-triangular matrix with **1s on the diagonal**. Each stock correlates perfectly with itself.

**The trick:**
- `MAX` or `LARGE(…,1)` returns 1 from the diagonal, not the answer.
- Every diagonal 1 sits at the top of the `LARGE` ordering.
- So the highest off-diagonal value is
  $$\text{LARGE}(\text{matrix},\; n+1)$$
  where $n$ is the number of 1s on the diagonal, i.e. the number of stocks.
- $k$ should not be hardcoded. Derive it from the size of the matrix.

**Conditional formatting rule** (Home → Conditional Formatting → New Rule → Use a formula). The matrix is assumed to sit in `B2:E5` with headers in row 1 and column A; this is inferred.
```excel
=B2=LARGE($B$2:$E$5, ROWS($B$2:$E$5)+1)
```

> **Discrepancy to check:** The instructor said values of $k$ below 6 all returned 1, so he used 6. He described this as "number of stocks + 1", which implies 5 ones on the diagonal (5 series). Yet the dataset was introduced as four stocks. Check against your file. The general principle is $k = (\text{count of 1s on the diagonal}) + 1$.

**Alternative without the k-trick** (array formula; not shown in class):
```excel
=B2=MAX(IF($B$2:$E$5<1,$B$2:$E$5))
```

### 2.6 Multiple Linear Regression: MPG Dataset

**Business problem:** Which variables significantly explain a car's fuel efficiency?

- Six columns: one dependent variable (`mpg`) and five independent variables.
- The independent variables were **cylinders, displacement, horsepower (HP), weight, acceleration**.

**Model:**
$$y = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \beta_3 x_3 + \beta_4 x_4 + \beta_5 x_5 + \varepsilon$$
Here $y$ = mpg and $x_1, \dots, x_5$ = the five predictors. The instructor wrote this informally as "$y = a x_1 + b x_2 + \dots$".

**ToolPak workflow:**
1. Go to **Data → Data Analysis → Regression → OK**.
2. **Input Y Range:** the mpg column (with header).
3. **Input X Range:** all five predictor columns (with headers).
4. Check **Labels**.
5. **Confidence Level:** 95% default; 99% etc. is optional.
6. Check **Residual Plots** (optional, shown in class).
7. Set an **Output Range** on the sheet and click **OK**.

**Interpreting the output:**
- Look at the **P-value** column of the coefficients table.
- A variable is significant at 95% confidence if $p < 0.05$.

**Result:**

| Variable | Significant? |
|---|---|
| Horsepower | Yes ($p < 0.05$) |
| Weight | Yes ($p < 0.05$) |
| Cylinders | No |
| Displacement | No |
| Acceleration | No |

**Answer: HP and Weight.**

**Fit:**
- $R^2 \approx 0.70$, with adjusted $R^2$ also about 70%. The transcript says "70% … 73 70%", so the exact figure is unclear.
- Most of the variation in mpg is explained by HP and weight.
- Dropping the three insignificant variables and re-running would give roughly the same $R^2$. They add little value.

**Residual plots** are produced too. The instructor suggested studying them on your own.

### 2.7 Histogram: Do Student Marks Follow a Normal Distribution?

**Task:**
- Create a histogram of student marks (range 0–50).
- Judge from the shape whether it looks like a bell curve, i.e. normal or Gaussian.
- **Context:** When grades go to the PGP/MSDSM office, the first page of the grade sheet is a histogram that the office checks for this shape.

**Common student mistakes:**
- Sorting the marks and plotting them. A sorted plot cannot show whether the distribution is bell-shaped.
- Pasting a whole worksheet instead of the chart.

**Manual logic (no ToolPak needed):**
1. Create **bins**: 0, 5, 10, …, 50.
2. Count how many students fall in each bin using a counting function.
3. Plot the counts as a simple **line or column chart**.
4. If most counts cluster in the middle, with few at the low and high ends, the shape is bell-like.

Marks are assumed to be in `B2:B101`, bin lower bounds in `D2:D11` and upper bounds in `D3:D12` (inferred).
```excel
=COUNTIFS($B$2:$B$101,">="&D2,$B$2:$B$101,"<"&D3)
```
or, matching the ToolPak's "≤ upper bound" convention:
```excel
=FREQUENCY($B$2:$B$101,$D$2:$D$12)
```

**ToolPak workflow:**
1. Go to **Data → Data Analysis → Histogram → OK**.
2. **Input Range:** the marks only, *without* the header.
3. **Bin Range:** the bin column. This is the key input; Excel counts the values per bin automatically.
4. **Labels:** unchecked, since no headers were selected.
5. **Output Range:** a cell on the sheet.
6. **Do not** check Pareto (sorted histogram).
7. Check **Chart Output**.
8. Click **OK**.

**Bin size matters:**
- The first attempt used bins 0, 1, 2, 3, …, which produced many zero counts. The chart looked wrong.
- Re-done with **0, 5, 10, 15, …, 50**, the chart showed a recognisable shape.

**Conclusion:**
- The shape is roughly bell-like but **not symmetric**.
- The bulk sits toward the **higher marks** (more B+ grades).
- A perfectly symmetric histogram is never expected in practice.

> Note on terminology: a student called this "skewed positive". When the mass sits at the high end with a tail toward low marks, that is technically **negative (left) skew**. Check the ToolPak's Skewness value: a negative number confirms left skew.

### 2.8 Course Recap (summary worksheet)

1. **Writing formulas, filtering, basic charting.** Using the formula bar and function arguments box.
2. **Text to Columns.** A critical data-cleaning feature.
3. **Naming cells.** Makes complex models readable later, e.g. `=Revenue*Margin` instead of `=B1*B5*B27`.
4. **Referencing:**
   - relative, absolute, and mixed references by placing `$`: `A1`, `$A$1`, `$A1`, `A$1`
   - circular references, which require enabling iterative calculation in File → Options → Formulas
5. **Advanced charting:**
   - missing data handled via Select Data → Hidden and Empty Cells → *Connect data points with line*
   - bullet charts and modified line charts
   - key rule: **multiple columns = multiple colours**
6. **In-cell charting:** conditional formatting (data bars, icon sets) and **sparklines**. There are three sparkline types:
   - Line
   - Column
   - **Win/Loss**: convert data to $-1, 0, 1$ first and plot that
7. **Formulas in charting.** E.g. using `REPT` to make text bar charts.
8. **Functions:**
   - Text: `LEN`, `LEFT`, `RIGHT`, `MID`. The assignment to split names into first, middle, and last was not done in class; try it at home.
   - Random: `RAND`, `RANDBETWEEN`. To generate 10 unique random numbers, combine `RAND` with `RANK`:
     ```excel
     A1:A10: =RAND()
     B1:    =RANK(A1,$A$1:$A$10)    ' unique integers 1–10
     ```
   - Others: `SUMPRODUCT`, `ROW`, `COLUMN`, `FV`, `PMT`, AI formulas.
   - SIP exercise: future value of regular investments via compound interest, i.e. future value of an annuity:
     $$FV = P \cdot \frac{(1+r)^n - 1}{r}\,(1+r)$$
   - EMI via PMT:
     $$\text{EMI} = \frac{P\, r\, (1+r)^n}{(1+r)^n - 1}$$
     ```excel
     =PMT(rate/12, years*12, -principal)
     ```
9. **Pivot tables and pivot charts.** A major exam focus. Dashboards with **slicers** and **timelines**.
10. **Lookup functions:**
    - `VLOOKUP` and `HLOOKUP` are table-based.
    - `XLOOKUP` and `XMATCH` are array-based, like `INDEX`/`MATCH`.
    - VLOOKUP conditions to remember: the lookup value must be in the **leftmost column**, and for approximate match the table must be **sorted ascending**.
11. **MATCH / INDEX.** Similar retrieval role to XLOOKUP/XMATCH.
12. **FILTER and SORT.** Can be combined with each other and with MATCH.
    > "The real skill is knowing which function is most appropriate for a given problem" — this comes only with practice.
13. **OFFSET.** Covered briefly. Used for dynamic tables and charts by shifting a reference to another location; also finding addresses.
14. **What-If Analysis:** one-way and two-way Data Tables, Goal Seek, Scenario Manager. Two sessions were spent on this.
15. **Developer tab:**
    - form controls (checkboxes, buttons, etc.)
    - conditional formatting with formulas
16. **This session:** macro recording, Analysis ToolPak (descriptive statistics, correlation, regression, histogram).
17. **Solver:** linear-programming optimisation. **Not covered** for lack of time; it requires understanding the LP concept.
