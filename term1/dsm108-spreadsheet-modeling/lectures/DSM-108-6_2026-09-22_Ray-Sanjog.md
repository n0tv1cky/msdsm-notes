## 1. Overview

This session introduced Excel's **retrieval functions**, starting with array-based retrieval and leaving table-based retrieval (VLOOKUP/HLOOKUP) for the next class.

- **Part 1: INDEX + MATCH.** Using a player dataset (player name, country, salary in lakhs), the instructor named the columns as ranges and used INDEX + MATCH to find the player and country for a given salary. He then showed how to return several columns at once with an array constant `{1,3}`.
- **The limitation.** MATCH/INDEX (and XLOOKUP) stop at the **first occurrence**, so they cannot return every player with the same salary.
- **Part 2: a "retrieval screen."** To handle multiple matches, he built a screen with a country drop-down (Data Validation → List). The screen lists all players and salaries for the chosen country using **FILTER**, then finds the highest-paid player, first with **SORT** and then, more robustly, with **FILTER + MAX** so that ties are handled.
- **Part 3: a past quiz problem.** Assign each employee the group label of the quarter with their second-highest sales, using **LARGE + MATCH + INDEX**.
- **Part 4: a variation.** When there is a tie, assign the group of the *latest* quarter instead, using **XMATCH** (or XLOOKUP) with search mode $-1$ to reverse the search direction.

**Key message:** knowing the functions is easy. The real skill (and what exams test) is choosing the right function for the scenario, breaking the problem into smaller steps, and testing the formula against edge cases such as ties.

## 2. Topics and Concepts (in order taught)

### 2.1 Families of retrieval functions

| Works on | Functions | When covered |
|---|---|---|
| An **array** (a single row or column) | `MATCH`, `INDEX` (plus `XMATCH`, `XLOOKUP`) | Today |
| A **table** | `VLOOKUP`, `HLOOKUP` | Next class |

### 2.2 Dataset: player salaries

- **Columns:** player name, country, salary in lakhs. Units: $1\text{ crore} = 100\text{ lakh}$.
- **Business question:** given a salary, what is the player's name and country?

**Step 1: name the columns.**
1. Select each column's data **without the header** (the instructor's preference).
2. Type a name in the Name Box (or use Formulas → Define Name).
3. Names used: `Name` (sometimes called "Player"), `Country`, `Salary`.

Two cautions:
- If you include the header for one column, include it for **all** of them.
- All named ranges must start on the **same row** (row 2 here). Otherwise, the position returned by MATCH will not line up with the row used by INDEX, and you will get wrong answers.

### 2.3 MATCH: find the position of a value in an array

Layout **[inferred cells]**:
- Input salary in `G2`, e.g. `30` (meaning 30 lakh).
- MATCH result in `G3`.
- INDEX outputs in `G4` and `G5`.

```excel
=MATCH(G2, Salary, 0)
```

- **Syntax:** `MATCH(lookup_value, lookup_array, match_type)`
- **`match_type = 0` means exact match.** The instructor called this "very critical": always choose exact match when you want an exact match.
- **Result in class:** 30 lakh is in the **6th position** of the `Salary` array.

### 2.4 INDEX: return the value at a position

```excel
=INDEX(Name, G3)        // player name (row 6 of the Name array)
=INDEX(Country, G3)     // country (student exercise)
```

Combined into a single formula (standard nesting):

```excel
=INDEX(Name,    MATCH(G2, Salary, 0))
=INDEX(Country, MATCH(G2, Salary, 0))
```

- **Syntax:** `INDEX(array, row_num, [column_num])`
- Because each named range is a single column, `column_num` can be left out.
- **Test case:** change the input to a value above 3 crore (300 lakh) and confirm the formula returns that player.

### 2.5 Returning multiple columns at once with an array constant `{ }`

- **First attempt (failed):** the instructor added `{1,3}` as the column argument while still pointing at the single-column `Name` range. This cannot work, because a one-column range has no column 3.
- **Fix:** point INDEX at the **whole data block** (all columns), then give the columns you want in curly brackets.

```excel
=INDEX($A$2:$C$200, MATCH(G2, Salary, 0), {1,3})     // [inferred range & column order]
```

- The result **spills** into two adjacent cells, so one formula replaces two.
- Use whatever column numbers correspond to Name and Country in your sheet's layout.
- **Concept:** curly brackets let you retrieve several columns with a single formula.

### 2.6 Limitation: only the first occurrence

- Several players share the same salary (about 10 players at 30 lakh), but MATCH/INDEX returns only the **first** one. It stops at the first hit.
- **To retrieve multiple values, use array functions** (FILTER, SORT).

### 2.7 Building the "retrieval screen" (exam-style task)

**Screen layout:**

| Element | Type | Content |
|---|---|---|
| Select Country | **Input** | Drop-down cell, e.g. `G9` [inferred] |
| Players | **Output** | Spilled list of players from that country |
| Salary | **Output** | Spilled list of their salaries |
| Player with highest salary | **Output** | Name(s) of the top-paid player(s) |

The instructor screenshotted the target screen for reference and said: *"Your exam question will be exactly like this. Some screen will be given. You have to design that."*

**Step A: list the unique countries.**
Copy the country values into a helper area. You can do this manually; the instructor copied them down. Removing duplicates or using `=UNIQUE(Country)` also works, but the transcript does not say which method he used **[inferred]**.

**Step B: create the drop-down (Data Validation).**
1. Click the input cell.
2. Go to **Data** tab → **Data Validation** → **Data Validation…**
3. Set **Allow:** to **List**.
4. Set **Source:** to the range of unique country names. You may also select the whole column.
5. Click **OK**. The cell now has a drop-down of countries.

There are multiple ways to make drop-downs; this was the one shown.

**Step C: list all players from the selected country with FILTER.**
Students were asked to try this on their own, without Google.

Demonstrated with a hard-coded country first:

```excel
=FILTER(Name, Country="Australia")
```

Then linked to the drop-down:

```excel
=FILTER(Name, Country=G9)
=FILTER(Salary, Country=G9)
```

- **Syntax:** `FILTER(array, include, [if_empty])`
- **Player and salary in one formula:** give FILTER a two-column array. If Name and Salary are adjacent, select both. If they are not adjacent, combine them first:

```excel
=FILTER(HSTACK(Name, Salary), Country=G9)    // [inferred – instructor selected "name column, salary"]
```

**Step D: player with the highest salary (multiple methods).**

**Method 1: SORT (the instructor's "simplest" first attempt)**

The instructor called this the simplest approach first ("Occam's razor"), though he later showed it is not the most robust. Sort the filtered name/salary array by column 2 (salary), descending:

```excel
=SORT(FILTER(HSTACK(Name, Salary), Country=G9), 2, -1)   // [inferred exact nesting]
```

- **Syntax:** `SORT(array, [sort_index], [sort_order])`, where `sort_index = 2` (salary column) and `sort_order = -1` (descending).
- Then point a cell at the first row of the sorted spill, e.g. `=K12` [inferred cell], to get the top player.
- **Check:** Australia gives Hazlewood (ASR: "h load"). England gives Butler.

**Why SORT alone is not the best answer: the tie test**
- The instructor created a scenario by changing Jos Buttler's salary to equal the top England salary (about 1250, in the dataset's units).
- The "first row of the sorted list" approach then shows only **one** name, even though two players share the top salary.

**Method 2: FILTER + MAX (the recommended, most efficient solution; works without sorting)**

```excel
=FILTER(Name, (Country=G9) * (Salary=MAX(FILTER(Salary, Country=G9))))
```

Equivalent version with MAXIFS:

```excel
=FILTER(Name, (Country=G9) * (Salary=MAXIFS(Salary, Country, G9)))
```

- The `*` combines the two conditions as a logical AND.
- This returns **all** tied top earners.
- The instructor's working version applied MAX as the filter condition on the sorted spill; the logic is the same.

**Why MATCH/INDEX and XLOOKUP fail here:**
- They are **not array functions**. They return one value and stop at the first occurrence.
- In the tie scenario they show only one name, so the formula is wrong.
- **Array functions in this course:** `SORT`, `FILTER` (and similar dynamic-array functions).

**How to tell if a result is an array (spilled) formula:**
- Click on the spilled cells. The formula exists only in the **top cell**.
- The other cells show the formula greyed out in the formula bar, and you cannot edit them individually.

**Rule given:** whatever formula you write, test it against the tie scenario. If there are multiple answers and you get only the first name, the formula is not right.

### 2.8 Exercise: second-highest quarter → group label (past quiz question)

**Business problem:**
- Each employee has sales in Q1–Q4.
- A group label (A, B, C, D, …) sits **at the top of each quarter column**.
- Assign each employee the group of the quarter where they had their **second-highest** sales.
- **Tie rule (version 1):** if two quarters tie, use the **earlier/older** quarter.

**Worked examples from class:**

| Employee | Second-highest sales | Where it occurs | Assigned group |
|---|---|---|---|
| ID 1 | 541 | Q1 | **A** |
| Next row | 318 | Appears in two quarters (tie) | **B** (the older quarter) |
| Next row | 372 | Under group A | **A** |

Expected output column: A, B, A, B, …

**Layout [inferred]:**

| Columns / rows | Role |
|---|---|
| `B2:E2` | Group labels above Q1–Q4 |
| `B3:E3` (first employee row) | Inputs: quarterly sales |
| `G` | Helper: second-highest value |
| `H` | Helper: position |
| `J` | Output: group |

**Solution in small steps** (the instructor stressed: *"always break into smaller parts"*):

Step 1: second-highest value.

```excel
=LARGE(B3:E3, 2)
```

Step 2: position of that value in the row (exact match is essential).

```excel
=MATCH(G3, B3:E3, 0)
```

Step 3: group label at that position. Press **F4** to make the header range absolute, so it stays fixed when copying down.

```excel
=INDEX($B$2:$E$2, H3)
```

Single-formula version:

```excel
=INDEX($B$2:$E$2, MATCH(LARGE(B3:E3, 2), B3:E3, 0))
```

- **Why ties go to the older quarter:** MATCH searches left to right and stops at the first hit.
- **Common mistake warned against:** forgetting `0` (exact match). Leaving it blank, or using `1` or `-1`, gives wrong positions.
- The instructor's comment: "It doesn't take even one minute to solve."

### 2.9 Variation: ties go to the latest quarter

- **New rule:** if the second-highest value appears in more than one quarter, assign the **latest** quarter.
- **Example:** the 318/318 tie now gives **C**, not B.
- **Hint given:** use **XLOOKUP** (or XMATCH).
  - Do not use nested IFs ("that's not a technique").
  - Do not use the old `LOOKUP` function ("very complicated… not very popular").

**Concept: default search direction.**
- Excel searches **left to right** (Q1 → Q4) and **top to bottom**.
- To favour the latest quarter, **reverse the direction** so the search runs last to first.

**XMATCH approach** (new helper column `I`):

```excel
=XMATCH(G3, B3:E3, 0, -1)
```

- **Syntax:** `XMATCH(lookup_value, lookup_array, [match_mode], [search_mode])`
- `match_mode = 0` means exact match.
- `search_mode = -1` means **search from last to first**.
- **Result:** for the tied row, the position becomes **3** instead of **2**.

Then point the INDEX formula at `I3` instead of `H3`:

```excel
=INDEX($B$2:$E$2, I3)
```

The answer changes from B to **C**.

**XLOOKUP alternative** (returns the label directly, no INDEX needed):

```excel
=XLOOKUP(LARGE(B3:E3, 2), B3:E3, $B$2:$E$2, , 0, -1)
```

- **Syntax:** `XLOOKUP(lookup_value, lookup_array, return_array, [if_not_found], [match_mode], [search_mode])`
- The instructor described XMATCH as the easier way to see the concept.
- **The key ingredient is the $-1$ search mode.**
- **Key aspect of the "X" functions:** they can change the direction in which the default search/retrieval happens.

### 2.10 Session recap (as summarised by the instructor)

1. MATCH + INDEX for single-value retrieval; curly brackets `{1,3}` to retrieve several columns in one formula.
2. Data Validation to create a drop-down.
3. FILTER to list all matches; SORT to rank them.
4. FILTER + MAX as the best way to find the top earner. It needs no sorting and handles ties.
5. Practice problem: LARGE + MATCH + INDEX.
6. XMATCH/XLOOKUP with search mode $-1$ to change the search direction.
