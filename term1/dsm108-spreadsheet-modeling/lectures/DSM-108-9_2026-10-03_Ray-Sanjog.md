## 2. Topics Covered (in order taught)

### 2.1 Enabling the Developer tab

- **Why it matters:** The Developer tab is mainly for writing **macros** and code in **VBA (Visual Basic for Applications)**. Here it is used for its **Insert → Form Controls**.
- **Steps:**
  1. **File → Options → Customize Ribbon**.
  2. In the right-hand dropdown, choose **Main Tabs** (or **All Tabs**).
  3. Tick **Developer**. If it isn't listed on the right, find it in the left list and click **Add >>** to move it across.
  4. Click **OK**. A **Developer** tab now appears on the ribbon.
- **Contents of the Developer tab:**
  - Visual Basic
  - Macros
  - Record Macro
  - Add-ins / Excel Add-ins
  - Insert (controls)
- **Add-ins housekeeping:** Go to **Developer → Excel Add-ins**, tick **Analysis ToolPak** and **Solver Add-in**, then click **OK**.
- **Form Controls vs ActiveX Controls:** Under **Developer → Insert** there are two groups. The instructor uses **only Form Controls**, not ActiveX ("please be clear on that").
- **Newer Excel versions** have a built-in in-cell checkbox at **Insert → Checkbox**. The Developer-tab route is taught so that everyone, including those on older versions, can follow.

### 2.2 Exercise 1: Number grid highlighted by checkboxes

**Business/teaching problem:** A grid of digits (0, 1, 2, 3, …) sits in a block of cells. Next to it is a set of checkboxes labelled with digits or digit groups. Ticking a checkbox highlights every grid cell containing that digit.

**Layout:**

| Element | Location |
|---|---|
| Data grid (digits) | `G11:L17` (the instructor also said "L7" once; `L17` is the consistent reading) |
| Checkboxes (Form Controls) | One per option: "0", "1", "2 or 3", … |
| Linked status cells | One cell per checkbox, chosen by the user; shows `TRUE`/`FALSE` **[exact cells inferred]** |
| Output | Conditional fill on the grid |

**Step 1: Add a Form Control checkbox**

1. **Developer → Insert → Form Controls → Check Box**.
2. Click to place it, for example next to the "0" label. Edit its text if desired.

**Step 2: Capture the checkbox state (the cell link)**

1. Right-click the checkbox → **Format Control → Control tab → Cell link**.
2. Pick a cell. That cell now shows `TRUE` when ticked and `FALSE` when unticked.
3. Repeat for every checkbox, giving each one its own link cell.
4. There are two ways to set the cell link: right-click → Format Control, or select the control and use **Properties**.
5. **Exam flag:** "In your exam I will definitely give some question on this."

**Step 3: Conditional formatting rule for "0" (green)**

1. Select the whole grid `G11:L17`, so the first (active) cell is `G11`.
2. **Home → Conditional Formatting → New Rule → "Use a formula to determine which cells to format"**.
3. Enter the formula. Make the grid reference **relative** (remove the `$` from `G11`) so it shifts across every cell. Keep the link cell **absolute**:

```excel
=AND(G11=0, $Z$1=TRUE)
```

- **[inferred]** `$Z$1` stands for the checkbox's linked cell. The ASR said "Z1"; substitute your own link cell.
- `=AND(G11=0,$Z$1)` works equally well, because the link cell already holds TRUE/FALSE.

4. **Format… → Fill → Green → OK**.

**Logic:** A cell is coloured if its value is 0 **and** the "0" checkbox is ticked.

**Troubleshooting from class:** The rule initially didn't work. Excel had wrapped the formula in **double quotes**, turning it into text. To fix it:

1. Go to **Conditional Formatting → Manage Rules**.
2. Edit the rule and delete the stray quotes manually.

**Rule for "1":** Same pattern, using `G11=1` and the "1" checkbox's link cell.

**In-class task: "2 or 3" in orange.** Students had 5 minutes. The solution combines `AND` with `OR`:

```excel
=AND(OR(G11=2, G11=3), $Z$3=TRUE)
```

- **[inferred]** `$Z$3` is the link cell of the "2 or 3" checkbox.
- Set the format to orange fill.
- The instructor noted there are multiple ways to write this. `AND`/`OR` is one of them.

### 2.3 Exercise 2: To-do task list with in-cell checkboxes

**Layout:**

- Labels "Task 1", "Task 2", … typed and filled down to **Task 10**.
- A checkbox column beside them. The formula `=A2` suggests the checkboxes start in `A2` **[inferred]**.

**Adding checkboxes (new Excel):**

1. Select all the target cells.
2. Click **Insert → Checkbox**.

**Key difference from Form Controls:**

| | Form Control checkbox | Insert → Checkbox (new) |
|---|---|---|
| Where TRUE/FALSE is stored | A separate **linked cell** | **Inside the cell itself** (not displayed as text) |
| Setup | Format Control → Cell link for each box | None; it is automatic |

**Fallback:** If you don't have Insert → Checkbox, use Form Control checkboxes with cell links. The instructor said doing it for two tasks is enough to demonstrate.

**Conditional formatting:**

1. Select the whole task range.
2. **Home → Conditional Formatting → New Rule → Use a formula**.
3. Enter:

```excel
=A2
```

4. Remove the `$` so the reference is relative and the rule applies to every row.
5. **Format… →** choose a format. The exact format wasn't stated; strikethrough or a fill colour are typical.

**Logic:** The cell already contains TRUE/FALSE, so `=A2` alone is the condition. If you want to format the task-name cell in the adjacent column, use a mixed reference such as `=$A2` **[inferred]**.

### 2.4 Exercise 3: Interactive chart that shows a series only when ticked

The instructor linked this to the **recent quiz question** (high/low, negative/positive shown in different colours), calling it a "trick question".

**Problem:** There are several product series, for example three lines. Each has a checkbox. Only the ticked series should be plotted.

**Layout [cell addresses inferred]:**

| Block | Content |
|---|---|
| Original data | Values per product across periods |
| Checkboxes | One per product, each with a linked cell (TRUE/FALSE) |
| Flag cells | Turn TRUE/FALSE into 1 or `#N/A` |
| Helper (plotted) data | Original value × flag |
| Chart | Line chart built on the helper data |

**Step 1: Flag cell for each product**

```excel
=IF(B1, 1, NA())
```

- `B1` is that product's checkbox link cell **[inferred]**.

**Step 2: Helper data**

Each cell multiplies the original value by the flag. Fix the flag with `$` so the formula fills across correctly:

```excel
=B5*$C$1
```

- **[inferred]** `B5` is the original value and `$C$1` is the product's flag cell.
- Fill across and down.

**Why `NA()`:** `#N/A` points are **not drawn** in line charts, so the series disappears.

- A value of 0 would draw a flat line on the axis.
- Blank text `""` can also behave badly.
- The instructor's verdict: "There are multiple ways… but the best thing is the NA thing."

**Step 3: Chart**

1. Select the helper data → **Insert → Line chart**.
2. Format the vertical axis: set **Maximum = 200**, because the default range looked "too long".
3. **Select Data → Edit Series** to give each series a proper name (the ASR mentioned a "products" range such as K2:K8). The instructor said this makes the chart understandable to readers.
4. Test it: unticking a checkbox removes that line.

### 2.5 Exercise 4: Income statement ratio dashboard

**Data set:** Income statement and balance sheet data for **2013, 2014, 2015**. The years sit in columns **D, E, F** respectively, with the first ratio in row 4 (from the formula `F4`/`E4`/`D4`).

**Part A: Fill the ratio table**

The formulas are simple divisions using the figures on the data tab.

**Tip:** While building a cross-tab formula, don't click back to a different tab before pressing Enter, or the reference "goes away".

| Ratio | Formula |
|---|---|
| Net profit margin | $\dfrac{\text{NPAT}}{\text{Sales}}$ |
| Asset turnover | $\dfrac{\text{Sales}}{\text{Total Assets}}$ |
| Equity multiplier (leverage) | $\dfrac{\text{Total Assets}}{\text{Shareholders' Funds (Equity)}}$ |
| Return on equity | $\dfrac{\text{NPAT}}{\text{Equity}}$ |

The ROE formula was garbled in the ASR ("return on equity by bad and bad"). This is the DuPont identity:

$$\text{ROE} = \frac{\text{NPAT}}{\text{Sales}}\times\frac{\text{Sales}}{\text{Total Assets}}\times\frac{\text{Total Assets}}{\text{Equity}} = \frac{\text{NPAT}}{\text{Equity}}$$

Excel examples **[cell addresses inferred]**:

```excel
=NPAT_cell/Sales_cell
=Sales_cell/TotalAssets_cell
=TotalAssets_cell/ShareholdersFunds_cell
```

**Part B: "Status" column (2015 vs 2013 and 2014)**

The rules:

- If 2015 > both earlier years → **"Better"**.
- If 2015 < both earlier years → **"Worse"**.
- Otherwise → a third label. This was not clearly audible; something like "Same" or "Average" **[inferred]**.

The solution is a nested `IF` with `AND`:

```excel
=IF(AND(F4>E4, F4>D4), "Better", IF(AND(F4<E4, F4<D4), "Worse", "Average"))
```

Fill this down for all four ratios.

**Colour coding:**

1. **Home → Conditional Formatting → Highlight Cells Rules → Equal To…**
2. Set "Worse" → red fill and "Better" → a positive colour such as green.
3. Add a rule for "Better" even if no row currently shows it. Design for **all possible values**, since the data may change.

**Part C: Show the Status only when a checkbox is ticked**

1. Add a checkbox next to the "Status" heading, using a Form Control with a cell link or an in-cell checkbox.
2. Wrap the status formula:

```excel
=IF($H$2, IF(AND(F4>E4, F4>D4), "Better", IF(AND(F4<E4, F4<D4), "Worse", "Average")), "")
```

- **[inferred]** `$H$2` is the status checkbox's cell (its link cell, or the cell containing the in-cell checkbox). Make it absolute so it fills down.
- You do **not** need `=TRUE`, because the cell already holds TRUE/FALSE.
- `""` (empty double quotes) means "show nothing".

**Common mistake corrected in class:** `NA` is **not** a string. `NA()` is a **function** (open and close brackets) that returns `#N/A`.

- Putting anything in double quotes makes it text. `"NA"` is just the letters N-A, not an error value.
- Here, for a blank result, use `""`. Don't write "NA" or anything else.

**Part D: Trend analysis with a Combo Box**

**Step 1: Insert the drop-down**

1. **Developer → Insert → Form Controls → Combo Box** (the second icon).
2. Draw it on the sheet.

**Step 2: Configure it**

1. Right-click → **Format Control**.
2. Set **Input range** to the list of the four ratio names, likely `$A$4:$A$7` **[inferred]**.
3. Set **Cell link** to a cell such as `$J$2` **[inferred from "J2"]**.
4. The link cell returns the **position number** of the selection (1–4), not the name. For example, choosing the third item shows 3.

**Step 3: Extract the selected row**

A student suggested `VLOOKUP`:

```excel
=VLOOKUP($J$2, $A$4:$G$7, col_num, FALSE)
```

- This only works if the first column of the table holds the numbers 1–4.
- The link cell is a position number, so it won't match ratio names in column A.
- The instructor said "I don't think it is wrong" but preferred `INDEX`.

The instructor's simpler method uses `INDEX` with the position number. Ratio name:

```excel
=INDEX($A$4:$A$7, $J$2)
```

Values for each year, using the whole table as the array:

```excel
=INDEX($A$4:$G$7, $J$2, 2)
=INDEX($A$4:$G$7, $J$2, 3)
=INDEX($A$4:$G$7, $J$2, 4)
```

- Continue this pattern for each column. **[inferred]** The exact column numbers depend on where the year columns sit.
- If dragging doesn't advance the column number, you can **hard-code 1, 2, 3, 4, 5, 6**, as some students did.
- Alternatively, reference a helper cell holding the column number, or use `COLUMN()`.
- `IFERROR(...)` was mentioned as a wrapper to hide errors:

```excel
=IFERROR(INDEX($A$4:$G$7, $J$2, 2), "")
```

**Known limitation:** Percentage formatting doesn't carry over. Some ratios are percentages and others are plain multiples, and getting the right format dynamically is "very complicated". The instructor left it as is.

**Step 4: Chart**

1. Select the extracted row (name and values) → **Insert → Line chart** (or a similar chart).
2. Changing the combo-box selection updates the table and the chart.
